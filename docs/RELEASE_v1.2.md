哈尔滨工业大学学术汇报 HTML 模板，支持离线放映与双屏演讲。

- **HIT 风格模板**：16:9 画布，包含封面、正文、图表、结尾与空白母版。
- **单文件离线放映**：资源内嵌，支持键盘、鼠标与触屏操作。
- **全屏与双屏**：同步翻页、选择播放屏幕、观众全屏与换屏。
- **总览与导航**：缩略图跳转、章节导航。
- **演讲者工作台**：当前页与下一页预览、逐页讲稿、全程与本页计时、字号和布局调整。
- **打印导出**：打印或另存为 PDF。
- **Windows 单文件启动**：一个 CMD 即可离线使用；首页与工作台窗口显示，观众页面默认在副屏全屏，支持一键结束。

**下载使用**

- `HIT-HTML.html`：用浏览器直接打开，适合单屏或手动双屏。
- `HIT-HTML-local.cmd`：Windows 用户双击运行，无需 Python 或管理员权限。将显示设为“扩展”，点击“演讲”并允许屏幕管理权限；结束时在终端按 `Q` 或 `Esc`（无需回车）。
