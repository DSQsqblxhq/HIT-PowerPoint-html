# 使用指南

## 1. 打开与放映

下载并解压仓库后，直接用浏览器打开 `HIT-HTML.html`。模板不依赖在线脚本、字体服务或后端，基础放映不需要联网。

页面按 1920 × 1080 画布等比例缩放。窗口比例不为 16:9 时会出现背景留白；这不会改变幻灯片内容。

将鼠标移至窗口底部可显示控制栏。点击“全屏”或按 `F` 切换全屏；浏览器对全屏操作有自身限制，具体以当前浏览器行为为准。

页面地址形如 `HIT-HTML.html#/2`，其中数字从 **0** 开始，`#/2` 表示第 3 页。

## 2. 替换文字与图片

用文本编辑器打开 HTML，查找“在此填写汇报题目”“学院 / 系”“姓名 / 职称”“YYYY 年 MM 月”等占位内容并替换。封面与结束页的人员信息需要分别修改。

正文位于各个 `<section class="slide ...">` 内，可以修改标题、段落、列表、表格和图示占位区域。演示页面不提供浏览器内直接编辑功能；修改源文件并保存后，需要刷新浏览器。

插入图片可以使用内联 SVG、图片的 data URI，或随项目一起携带的本地图片。使用本地图片路径后，HTML 将不再是可独立分发的单文件；移动文件时需一起保留对应图片。

表格中的破折号为待填写数据，不代表真实实验结果。

## 3. 修改章节导航

找到 `CONFIG`：

```js
const CONFIG = {
  width: 1920,
  height: 1080,
  sections: [
    { title: '研究背景', page: 3 },
    { title: '研究内容', page: 4 },
    { title: '实验结果', page: 6 },
    { title: '总结展望', page: 7 }
  ]
};
```

- `title` 为目录及顶部导航显示的章节名称。
- `page` 为章节跳转的目标页码，从 **1** 开始计算。
- 每页的 `data-section` 为章节数组下标，从 **0** 开始；`-1` 表示不高亮任何章节。
- `data-chapter-name="0"` 会将该元素文字替换为第一个章节的标题。

初始导航按 4 个章节设计；增加章节或使用较长标题后，需要自行检查顶部排版。修改画布尺寸时，请同时调整 CSS 变量、`CONFIG.width/height` 和打印样式中的尺寸。

## 4. 新增、移动或删除页面

1. 复制一个完整的 `<section class="slide"> ... </section>`，或移动、删除现有页面。
2. 为页面设置合适的 `aria-label` 和 `data-section`。
3. 按新的页面顺序更新 `CONFIG.sections` 中的目标页码。
4. 同步新增、移动或删除 `NOTES` 中对应条目。

页脚页码及控制栏总页数会自动计算。不要复制 `brand-header` / `brand-footer` 模板或控制栏，它们由脚本统一复用。

最后一页为空白母版；正式导出前，删除不需要的页面，避免多出一页。

## 5. 修改讲稿与排练时长

`NOTES` 按幻灯片顺序逐页对应。例如：

```js
{
  text: '【研究背景】这里填写背景。\n\n【核心问题】这里填写核心问题。',
  seconds: 60,
  source: '资料来源说明',
  references: ['[1] 作者. 文献题名. 年份.']
}
```

- `text` 为讲稿；两个换行分段，每段开头的 `【小标题】` 会显示为段落标题。
- `seconds` 为本页建议秒数，`0` 表示未设置。总时长预算由各页自动相加。
- `source` 为本页资料来源，可以留空。
- `references` 为文献列表，展示在“本页引用文献”折叠区域中。

按 `N` 打开讲稿面板，使用顶部“上一页 / 下一页”按钮可同步切换页面。计时为全程累计，翻页不会自动归零；关闭面板后继续计时，刷新页面后重置。讲稿与计时数据不写入本地存储。

桌面窗口打开面板时，幻灯片会缩小以预留侧栏空间；窄屏下，面板显示在底部。

## 6. 打印与导出 PDF

1. 点击底部“打印”按钮，选择打印机或“另存为 PDF”。
2. 检查预览中是否为一页幻灯片对应一页纸，页面方向为横向。
3. 开启背景图形，关闭浏览器附加的页眉和页脚；检查纸张大小、边距与缩放设置。
4. 浏览器若未采用 CSS 设定的 16:9 页面尺寸，请在打印预览中调整纸张与缩放，避免裁切。

模板打印样式会显示全部页面，隐藏放映控制栏和讲稿面板。打印效果可能受浏览器及打印设置影响，导出前请检查预览。

## 7. 字体与标识

`HITLettering` 是内嵌的固定校名、英文校名和校训字形资源，并非完整中文字库，不适合用于任意新增文字。正文使用系统字体回退列表，因此不同设备的正文换行和字宽可能略有差异。

建筑标志以 SVG 内嵌；其文件内说明为根据参考图片重建。本项目不将该图形认定为官方标准矢量文件。素材来源与许可范围见 [第三方说明](../THIRD_PARTY_NOTICES.md)。
