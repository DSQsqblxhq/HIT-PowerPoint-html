# 使用指南

## 1. 打开与放映

下载并解压仓库后，直接用浏览器打开 `HIT-HTML.html`。模板不依赖在线脚本、字体服务或后端，基础放映不需要联网。

需要在本地自动将观众窗口投放到副屏时，Windows 用户只需下载并双击 [HIT-HTML-local.cmd](https://github.com/DSQsqblxhq/HIT-PowerPoint-html/releases/download/v1.2/HIT-HTML-local.cmd)。HTML、启动服务、说明和来源许可都在这一个文件中，不需要配套文件；[兼容 ZIP](https://github.com/DSQsqblxhq/HIT-PowerPoint-html/releases/download/v1.2/HIT-HTML-local-v1.2.zip)中也仅有同一个 CMD。浏览器会通过 `http://127.0.0.1:8765/HIT-HTML.html` 读取内嵌页面，不依赖公网。无需安装 Python，也不需要管理员权限；演示期间保持启动窗口打开，结束后按 `Ctrl+C` 关闭本机服务。端口占用时，启动器会选择后续可用端口，以命令行显示的地址为准。

启动器优先使用已安装的 Edge 或 Chrome；若未自动打开，请将显示的地址复制到新版 Edge / Chrome。编辑时用文本编辑器打开该 CMD，在末尾找到 `<!doctype html>`，修改后面的 HTML，保留前面的启动代码和分隔标记，按 UTF-8 保存后刷新即可。服务每次请求都从 CMD 自身重新读取页面，不会解压或生成临时 HTML。若编辑器使用 CRLF 换行也可以正常启动。

单个 `.html` 不能自行启动本机服务，因此该自动本地双屏版本使用 `.cmd` 扩展名；原 `HIT-HTML.html` 的直接放映方式继续保留。仓库开发者可运行 `python tools/package_local.py`，从根目录 HTML 和启动器源代码生成 `dist/HIT-HTML-local.cmd`；这是构建步骤，使用者无需 Python。

页面按 1920 × 1080 画布等比例缩放。窗口比例不为 16:9 时会出现背景留白；这不会改变幻灯片内容。

将鼠标移至窗口底部可显示控制栏。点击“全屏”或按 `F` 切换全屏；浏览器对全屏操作有自身限制，具体以当前浏览器行为为准。

页面地址形如 `HIT-HTML.html#/2`，其中数字从 **0** 开始，`#/2` 表示第 3 页。

## 2. 替换文字与图片

用文本编辑器打开 HTML，替换封面的“在此填写汇报题目”和英文题目 `ENTER YOUR PRESENTATION TITLE HERE`，以及院（系）、指导教师、答辩人、答辩时间各项方括号内的占位信息。封面与结束页的标题需要分别修改。

封面中文标题预留两行高度，单行题目会在两行区域内垂直居中；英文题目使用大写字母，在一行网格高度内垂直居中。中文标题上方实线随中文标题宽度调整，下方浅色实线随英文题目宽度调整。信息按 2×2 排列，标签统一按四字宽度对齐。

正文位于各个 `<section class="slide ...">` 内，可以修改标题、段落、列表、表格和图示占位区域。演示页面不提供浏览器内直接编辑功能；修改源文件并保存后，需要刷新浏览器。

插入图片可以使用内联 SVG、图片的 data URI，或随项目一起携带的本地图片。使用本地图片路径后，HTML 将不再是可独立分发的单文件；移动文件时需一起保留对应图片。

表格中的破折号为待填写数据，不代表真实实验结果。

## 3. 修改章节导航

找到 `CONFIG`：

```js
const CONFIG = {
  width: 1920,
  height: 1080,
  sections: [
    { title: '研究背景', page: 3 },
    { title: '研究内容', page: 4 },
    { title: '实验结果', page: 6 },
    { title: '总结展望', page: 7 }
  ]
};
```

- `title` 为目录及顶部导航显示的章节名称。
- `page` 为章节跳转的目标页码，从 **1** 开始计算。
- 每页的 `data-section` 为章节数组下标，从 **0** 开始；`-1` 表示不高亮任何章节。
- `data-chapter-name="0"` 会将该元素文字替换为第一个章节的标题。

初始导航按 4 个章节设计；增加章节或使用较长标题后，需要自行检查顶部排版。修改画布尺寸时，请同时调整 CSS 变量、`CONFIG.width/height` 和打印样式中的尺寸。

## 4. 新增、移动或删除页面

1. 复制一个完整的 `<section class="slide"> ... </section>`，或移动、删除现有页面。
2. 为页面设置合适的 `aria-label` 和 `data-section`。
3. 按新的页面顺序更新 `CONFIG.sections` 中的目标页码。
4. 同步新增、移动或删除 `NOTES` 中对应条目。

页脚页码及控制栏总页数会自动计算。不要复制 `brand-header` / `brand-footer` 模板或控制栏，它们由脚本统一复用。

最后一页为空白母版；正式导出前，删除不需要的页面，避免多出一页。

## 5. 修改讲稿与排练时长

`NOTES` 按幻灯片顺序逐页对应。例如：

```js
{
  text: '【研究背景】这里填写背景。\n\n【核心问题】这里填写核心问题。',
  seconds: 60,
  source: '资料来源说明',
  references: ['[1] 作者. 文献题名. 年份.']
}
```

- `text` 为讲稿；两个换行分段，每段开头的 `【小标题】` 会显示为段落标题。
- `seconds` 为本页建议秒数，`0` 表示未设置。总时长预算由各页自动相加。
- `source` 为本页资料来源，可以留空。
- `references` 为文献列表，展示在“本页引用文献”折叠区域中。

点击底部“演讲者”或按 `S` 进入工作台。工作台显示当前页、下一页、本页讲稿，以及全程和本页计时；点击下一页预览也可以翻页。讲稿卡片中的 `A−` / `A＋` 可调整字号。资料来源与文献引用随当前页同步。

计时在观众窗口首次进入全屏时自动开始，也可用“开始计时 / 暂停 / 继续”手动控制。“重置”或 `R` 清零计时；翻页会重新计算本页时间，全程时间继续累计。刷新同一工作台或观众窗口可恢复当前页、计时与连接。

桌面窗口可拖动卡片标题调整位置，拖动右下角调整大小；“重置布局”恢复默认排布。布局和讲稿字号会在浏览器允许本地存储时保存，窄屏自动采用网格排布。

### 双屏放映

网页、`file://` 本地文件与 `127.0.0.1` 本机地址的屏幕管理授权不会互相继承。直接双击 HTML 能否自动选择副屏取决于当前浏览器对本地文件的授权；若在线版能投放而本地文件不能，请使用上述单文件 CMD，在本机地址重新授权。页面不能强制绕过浏览器权限。

1. 将系统显示方式设为“扩展”，在普通放映中点击“演讲者”或按 `S`。
2. 若浏览器询问屏幕管理权限，先完成授权；观众窗口在询问结束后打开。若弹窗被拦截，允许弹窗后在工作台点击“打开播放窗”或按 `O`。
3. 取得屏幕管理权限后，观众窗口默认在副屏打开，并在加载后确认位置、自动重试定位。需要切换屏幕时，点击“识别屏幕”并选择播放屏幕；下拉框应列出实际屏幕。未取得权限时不会自动全屏，也不会显示已投放成功；请检查当前地址的站点权限并点击“识别屏幕”重试，或手动将观众窗口拖到副屏。
4. 在工作台点击“副屏全屏”或按 `F`，直接让观众窗口进入全屏，无需在观众窗口再次点击。全屏请求失败时，工作台会显示原因并恢复按钮，便于重试；观众底栏的“全屏”仍可独立使用。
5. 任一窗口翻页都会同步到另一窗口。观众底栏包含上一页、页码、下一页、总览和全屏；讲稿与计时位于工作台。
6. 在工作台点击“退出”或按 `Esc` 返回普通放映，并关闭由工作台打开的观众窗口。

本地 HTML 在工作台或观众窗口刷新后，若提示播放窗口已重新连接，再在工作台点击一次“副屏全屏”或按 `F` 即可。重新连接会保留当前页与计时，不需要点击观众窗口。

本地启动脚本只监听 `127.0.0.1`，只提供内嵌 HTML；其他设备不能通过该服务访问文件。`HIT-HTML-local.cmd` 的 `ExecutionPolicy Bypass` 只作用于本次 PowerShell 进程，不修改系统执行策略。若所在设备的组织策略禁止脚本执行，请使用在线版，或直接打开 HTML 并手动移动观众窗口。

### 幻灯片总览

点击“总览”或按 `G` 打开所有页面的缩略图，点击预览即可跳转。普通放映和观众窗口也可按 `O` 打开总览；工作台中的 `O` 用于打开播放窗。在总览中可用方向键或 `Home` / `End` 选择页面，按 `Esc` 关闭。

## 6. 打印与导出 PDF

1. 点击底部“打印”按钮，选择打印机或“另存为 PDF”。
2. 检查预览中是否为一页幻灯片对应一页纸，页面方向为横向。
3. 开启背景图形，关闭浏览器附加的页眉和页脚；检查纸张大小、边距与缩放设置。
4. 浏览器若未采用 CSS 设定的 16:9 页面尺寸，请在打印预览中调整纸张与缩放，避免裁切。

模板打印样式会显示全部页面，隐藏放映控制栏、总览和演讲者工作台。打印效果可能受浏览器及打印设置影响，导出前请检查预览。

## 7. 字体与标识

`HITLettering` 是内嵌的固定校名、英文校名和校训字形资源，并非完整中文字库，不适合用于任意新增文字。正文使用系统字体回退列表，因此不同设备的正文换行和字宽可能略有差异。

建筑标志以 SVG 内嵌；其文件内说明为根据参考图片重建。本项目不将该图形认定为官方标准矢量文件。素材来源与许可范围见 [第三方说明](THIRD_PARTY_NOTICES.md)。
