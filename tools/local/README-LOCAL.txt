HIT HTML 本地双屏启动包（Windows）

1. 将压缩包完整解压到同一文件夹，不要在压缩包内部直接运行。
2. 连接副屏，将 Windows 显示设置改为“扩展这些显示器”。
3. 双击 Start-Presentation.cmd。脚本优先打开已安装的 Edge 或 Chrome。
4. 点击页面底部“演讲者”，允许浏览器对 127.0.0.1 的屏幕管理请求。
   网页版的授权不会继承给本机地址，需要在首次使用时单独允许。
5. 观众窗口在权限询问结束后打开。弹窗被拦截时，允许后点击“打开播放窗”。
   工作台可选择播放屏幕，点击“副屏全屏”进入全屏。

仍然使用本地 HIT-HTML.html，不会上传文件，不需要联网、Python 或管理员权限。
请保持启动时出现的命令行窗口打开；结束后按 Ctrl+C 关闭本机服务。
修改同一文件夹内的 HIT-HTML.html，保存并刷新浏览器即可。
默认地址为 http://127.0.0.1:8765/HIT-HTML.html；端口占用时会自动选择后续端口。
如果浏览器没有自动打开，将命令行显示的地址复制到新版 Chrome 或 Edge。
如先前拒绝授权，可在该本机地址的站点设置中重新允许屏幕管理和弹出式窗口。

直接双击 HIT-HTML.html 仍可离线放映；自动跨屏取决于浏览器是否允许本地文件
取得屏幕信息。网页无法代替用户授权；未能授权时请使用上述本机启动方式，
或手动将观众窗口拖到副屏。

启动脚本只在当前进程中使用 ExecutionPolicy Bypass，不修改系统执行策略。
本机服务仅监听 127.0.0.1，仅提供该 HTML，不提供其他本地文件。
